# 🌸 Трекер расходов 🌸

Консольное приложение на Python для учёта личных расходов 💰

##  Возможности
- 🌼 добавление расхода (сумма, категория, дата)
- 🌼 просмотр списка расходов
- 🌼 сохранение данных в файл
- 🌼 статистика по категориям

##  Запуск
python src/main.py

##  Тесты
python -m unittest discover -s tests -t .

##  Документация
- 📖 подробная инструкция: [docs/INSTRUCTION.md](docs/INSTRUCTION.md)
- 📚 документация по коду: `doxygen Doxyfile`, затем открыть docs/html/index.html
