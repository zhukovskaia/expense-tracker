# Инструкция

## 1. Установка

Нужен Python 3.8 или новее. Сторонние библиотеки не требуются.

```
git clone https://github.com/zhukovskaia/expense-tracker.git
cd expense-tracker
```

## 2. Запуск

Из корня проекта:

```
python src/main.py
```

Расходы сохраняются в файл `expenses.json` в папке, из которой запущена программа.

## 3. Работа с программой

После запуска появляется меню:

```
=== Учёт расходов ===
1. Добавить расход
2. Показать все расходы
3. Статистика по категориям
4. Удалить расход
5. Фильтр по категории
0. Выход
```

### 1 — Добавить расход

Программа по очереди спрашивает:

| Поле | Что вводить | Пример |
|---|---|---|
| Категория | любой текст, не пустой (регистр не важен) | `Еда` |
| Сумма | число больше нуля, можно с запятой | `350` или `99,90` |
| Дата | `ГГГГ-ММ-ДД` или Enter — сегодня | `2026-10-16` |
| Комментарий | необязательно, можно нажать Enter | `обед` |

При неверном вводе программа покажет ошибку и спросит ещё раз.

### 2 — Показать все расходы

```
--- Все расходы ---
1. 2026-10-16 | еда — 350.0 руб. (обед)
2. 2026-10-17 | транспорт — 60.0 руб.
-------------------
```

### 3 — Статистика по категориям

Сумма по каждой категории, её доля и общий итог:

```
--- Статистика по категориям ---
еда: 350.00 руб. (85.4%)
транспорт: 60.00 руб. (14.6%)
--------------------------------
Итого: 410.00 руб.
```

### 4 — Удалить расход

Программа показывает список и спрашивает номер расхода, который нужно удалить.

### 5 — Фильтр по категории

Показывает расходы только выбранной категории. Регистр не важен: `ЕДА` найдёт `еда`.

### 0 — Выход

Все данные уже сохранены в файл, отдельно сохранять ничего не нужно.

## 5. Документация Doxygen

Документация собирается из комментариев в коде (`src/`).

1. Установить Doxygen: `winget install DimitriVanHeesch.Doxygen`
   или скачать с https://www.doxygen.nl/download.html
2. Из корня проекта выполнить:
   ```
   doxygen Doxyfile
   ```
3. Открыть `docs/html/index.html` в браузере.

Папка `docs/html/` не хранится в git — её нужно сгенерировать самостоятельно.

### Как писать комментарии

Комментарий функции — строка документации, начинающаяся с `"""!`:

```python
def add_expense(category, amount, date, comment=""):
    """!
    @brief Добавляет расход и сохраняет его в файл.

    @param category Категория.
    @param amount Сумма.
    @param date Дата в формате ГГГГ-ММ-ДД.
    @param comment Комментарий (необязательно).
    """
```

- `@file`, `@brief` — в начале каждого файла;
- `@brief` — кратко, что делает функция;
- `@param имя` — описание параметра;
- `@return` — что возвращает функция;
- `##` — комментарий к переменной модуля.
